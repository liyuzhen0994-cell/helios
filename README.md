# Helios 掉落小站

点击屏幕就会掉下一只会动的 Helios 玩偶，堆成一堆，还会说话。

## 基础玩法

- **点一下**：掉 1 只 Helios，同时喊一声 "wei"；
- **按住不放**：连发，按住越久掉得越快；
- 玩偶落地会**挤压变形**，堆在一起互相挤压，最多 100 只（可解除上限）。

## 稀有度

掉出来的玩偶随机抽：

| 款式 | 概率 | 特别之处 |
|---|---|---|
| 普通款 | 大多数 | 4 张动图随机，只喊 wei |
| 特殊 1 | 1/250 | 专属动图 + 专属语音 + 星光粒子 |
| 特殊 3 | 1/40 | 专属动图 + 专属语音 + 星光粒子 |

## 隐藏菜单

右下角最角落的 **"⋯"**，点开有四个开关 + 一个入口：

- **Unlimited Helios Works** —— 解除 100 只上限（开了就关不掉），屏幕左上角显示数量，堆太高镜头会自动拉远；
- **Mobile Gravity Mode** —— 手机专属：**倾斜手机**改变重力方向（手机倒过来玩偶全掉到天花板）；**摇一摇**把玩偶炸散；
- **Takeoff Mode 起飞** —— 手机摇一摇，全场玩偶飞起来再缓缓飘落（电脑上按 **T** 键模拟摇一摇）；
- **Audio** —— 语音开关（默认开）；
- **📊 掉落排行榜** —— 看榜、上报成绩、改昵称、查成就。

## 成就

解锁时屏幕顶部会弹金色提示：

| 成就 | 怎么拿 |
|---|---|
| 🐣 初次wei面 | 掉下第 1 只 Helios |
| 🚀 wei到飞起 | 按住连发超过 5 秒 |
| ☀️ 太阳神能飞~ | 开启重力模式后摇一次手机 |

## 排行榜

- 每掉 1 只都会累计，存进本机，永久不清零；
- 昵称第一次自动起好（可以改）；
- 打开排行榜自动上报，也会顺手补报你关页面前的成绩；
- 同一台设备只占一个名次（重复上报会覆盖自己）；
- 榜单按掉落数从高到低排前 20 名。
